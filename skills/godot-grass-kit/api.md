# API de GrassKit por pieza

Todo está en `addons/grass_kit/`. Los puntos del plano del suelo son `Vector2` (x, z) en metros del mundo.

| Clase | Qué |
|---|---|
| `GrassField3D` (@tool) | `ground`, `look`, `quality`, `wind`, `enabled`; «Bake ground»; Clearings: `clearings`; Trampling: `trample_group`, `trample_radius`, `trample_recover`; Camera: `camera`, `center`; Editor: `editor_preview`, `editor_radius`. `ground_bake_view`; `set_up() -> PackedStringArray`, `colliders_area(meshes_too = true) -> Rect2`, `bake_ground() -> int`, `bake_ground_color() -> Image` (await), `ground_changed(at: Vector3, radius)`, `refresh_clearings()`, `can_draw()`; `stats` (GrassStats); estático `draw_anywhere` (tests); constantes `SHADER`, `CUT_SHADER`, `DEFAULT_LOOK` |
| `GrassGround` | `area`, `texel_size`, `collision_mask`, `slope_fade` (grados), `flat_height`; Painted maps: `density_texture`, `size_texture`, `color_texture` (el alfa cubre el color de suelo del look), `kind_maps` (por el `map_name` de un tipo), `paint_texel_size`, `color_layers` (lo que ve «Bake ground colour»); horneado `data` (RGBA float: altura, normal x, normal z, suelo). Alturas: `bake(space, rect = todo) -> int`, `set_heights(rect, sampler)`, `set_heights_image(image, rect = todo)`, `height_at(at)`, `normal_at(at)`, `has_ground(at)`, `slope_at(at)`, `slope_keep(at)`, `height_range_in(rect)`, `ray_hit(from, direction, max_distance) -> Vector3 o null`, `restore_data(image)`. Mapas (`DENSITY`, `SIZE`, `COLOR` o el nombre de un tipo): `paint(map, at, brush, pressure = 1) -> Rect2i`, `fill_map(map, value)`, `clear_map(map)`, `import_map(map, image)`, `export_map(map) -> Image`, `map_texture(map)`, `set_map_texture(map, texture)`, `map_size(map)`, `new_map_size()`, `map_region(map, rect)`, `set_map_region(map, region, at)`, `put_map(map, texture, region, at)`, `editable_map(map)`, `map_empty_in(map, rect)`, `painted_kinds()`, `flush_maps()`, estáticos `map_rest(map)`, `map_erased(map)`. Área: `resize_area(rect)`, `layout()`, `set_layout(saved)`. `ground_texture()`, `bake_cost() -> Vector2` (rayos, MB), `texture_size()`; señales `area_changed(rect)`, `map_painted(map)` |
| `GrassBrush` | `radius`, `strength`, `falloff`, `noise`, `value`, `mode` (PAINT, ERASE, SMOOTH). `dab(image, area, at, erased, pressure = 1) -> Rect2i`, `weight_at(distance)` |
| `GrassMap` (ImageTexture) | Un mapa pintado guardado en su suelo: `source` (la imagen pintada, lo que se guarda); estático `from(image)`, `refresh()` |
| `GrassLook` | Forma: `height_range`, `width`, `tip_width`, `lean`, `align_to_normal`, `clump_size`. Color: `base_color`, `tip_color`, `color_variation`, `ground_tint`, `ground_color`, `fade_to_ground`, `roughness`. Luz: `translucency`, `root_shade`, `roundness`, `view_thicken`. Viento: `wind_response`, `flutter`, `gust_lighten`. Distancia: `far_grass`. El suelo bajo el pasto: `under_grass`, `under_relief`. Mallas: `meshes: Array[GrassMesh]`. `kinds()`, `build_key()`, `average_color()`, `ground_under() -> Vector4`, `apply_to(material)`. Listos en `looks/`: meadow, autumn, lush, steppe |
| `GrassMesh` | `mesh` (null = la hoja del kit), `weight`, `size`, `map_name`, `mask_texture`; Material: `albedo_texture`, `normal_texture`, `orm_texture`, `alpha_scissor`, `tint`, `palette`, `bend_from_color`. `grows_by_map()`, `build_key()` |
| `GrassWind` | `direction`, `strength`, `speed`, `scale`, `noise`, `blend_time`, `time_override`; `current_direction`, `current_strength`, `offset`, `time`. `tick(delta)` (una vez por frame), `write()`, estático `write_calm()` |
| `GrassQuality` | `density`, `radius`, `near_radius`, `far_density`, `cell_size`, `tiers`, `segments`, `min_blade_pixels`, `near_fade`, `cast_shadows`; botones Low / Medium / High en el inspector y `cost` de solo lectura. estático `preset(Level.LOW / MEDIUM / HIGH)`; `apply_preset(level)`, `density_at(distance)`, `blades_per_cell()`, `tier_starts()`, `tier_at(distance)`, `blades_in_tier(tier)`, `segments_in_tier(tier)`, `morph_ends()`, `ring_margin()`, `blades_in_ring()`, `describe()` |
| `GrassClearing` | `group`, `radius`, `soft` |
| `GrassClear3D` | `radius`, `soft` (gizmo y asas en el editor); señal `changed` |
| `GrassStats` | `cells`, `blades`, `cells_in_view`, `blades_in_view`, `draws`, `blades_by_kind`; se imprime en una línea |
| `GrassGlobals` | Los globales de shader (`ALL`); estáticos `declare()`, `add_to_project()`, `bake_view(look, ground) -> Dictionary`, `write_bake_view(look, ground)` |
| `GrassCells` | estáticos `around(center, radius, size) -> Dictionary[Vector2i, float]`, `rect_of(cell, size)` |
| `GrassBlades` | estáticos `points(count, size, start)`, `kinds_of(count, weights)`, `instance_buffer(points, count, kinds, kind, segments)`, `blade_mesh(segments)`, `tier_meshes(quality, kinds)` |
| `field/grass.gdshader`, `field/grass_cut.gdshader` | Las hojas, opacas y con alpha scissor (el cuerpo está en `grass_body.gdshaderinc`) |
| `field/grass_wind.gdshaderinc` | Para cualquier shader: `grasskit_wind_wave(xz)`, `grasskit_wind_gust(xz)`, `grasskit_wind_push(xz)` |
| `field/grass_ground.gdshaderinc` | Para el suelo del juego: `grasskit_ground_color(rgb, xz, grass_here)`, `grasskit_painted_grass(xz)`, `grasskit_ground_bands(xz, amount)` |
| `field/grass_color.gdshaderinc` | `grasskit_to_linear(rgb)`, `grasskit_from_linear(rgb)`: los colores del renderer a lineal y de vuelta (Compatibility convierte, los otros no) |
| Editor (plugin) | El menú GrassKit y los pinceles de la vista 3D (`editor/grass_paint_tool.gd`), asas (`editor/grass_gizmos.gd`), Proyecto ▸ Herramientas ▸ GrassKit: Bake the open scene |
