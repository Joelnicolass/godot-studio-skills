# GrassKit API by piece

All under `addons/grass_kit/`. Ground-plane points are `Vector2` (x, z) in world metres.

| Class | What |
|---|---|
| `GrassField3D` (@tool) | `ground`, `look`, `quality`, `wind`, `enabled`; «Bake ground»; Clearings: `clearings`; Trampling: `trample_group`, `trample_radius`, `trample_recover`; Camera: `camera`, `center`; Editor: `editor_preview`, `editor_radius`. `ground_bake_view`; `set_up() -> PackedStringArray`, `colliders_area(meshes_too = true) -> Rect2`, `bake_ground() -> int`, `bake_ground_color() -> Image` (await), `ground_changed(at: Vector3, radius)`, `refresh_clearings()`, `can_draw()`; `stats` (GrassStats); static `draw_anywhere` (tests); constants `SHADER`, `CUT_SHADER`, `DEFAULT_LOOK` |
| `GrassGround` | `area`, `texel_size`, `collision_mask`, `slope_fade` (degrees), `flat_height`; Painted maps: `density_texture`, `size_texture`, `color_texture` (alpha covers the look's ground colour), `kind_maps` (by a kind's `map_name`), `paint_texel_size`, `color_layers` (what «Bake ground colour» sees); baked `data` (RGBA float: height, normal x, normal z, ground). Heights: `bake(space, rect = all) -> int`, `set_heights(rect, sampler)`, `set_heights_image(image, rect = all)`, `height_at(at)`, `normal_at(at)`, `has_ground(at)`, `slope_at(at)`, `slope_keep(at)`, `height_range_in(rect)`, `ray_hit(from, direction, max_distance) -> Vector3 or null`, `restore_data(image)`. Maps (`DENSITY`, `SIZE`, `COLOR` or a kind's name): `paint(map, at, brush, pressure = 1) -> Rect2i`, `fill_map(map, value)`, `clear_map(map)`, `import_map(map, image)`, `export_map(map) -> Image`, `map_texture(map)`, `set_map_texture(map, texture)`, `map_size(map)`, `new_map_size()`, `map_region(map, rect)`, `set_map_region(map, region, at)`, `put_map(map, texture, region, at)`, `editable_map(map)`, `map_empty_in(map, rect)`, `painted_kinds()`, `flush_maps()`, static `map_rest(map)`, `map_erased(map)`. Area: `resize_area(rect)`, `layout()`, `set_layout(saved)`. `ground_texture()`, `bake_cost() -> Vector2` (rays, MB), `texture_size()`; signals `area_changed(rect)`, `map_painted(map)` |
| `GrassBrush` | `radius`, `strength`, `falloff`, `noise`, `value`, `mode` (PAINT, ERASE, SMOOTH). `dab(image, area, at, erased, pressure = 1) -> Rect2i`, `weight_at(distance)` |
| `GrassMap` (ImageTexture) | A painted map kept in its ground: `source` (the painted image, what is saved); static `from(image)`, `refresh()` |
| `GrassLook` | Shape: `height_range`, `width`, `tip_width`, `lean`, `align_to_normal`, `clump_size`. Colour: `base_color`, `tip_color`, `color_variation`, `ground_tint`, `ground_color`, `fade_to_ground`, `roughness`. Light: `translucency`, `root_shade`, `roundness`, `view_thicken`. Wind: `wind_response`, `flutter`, `gust_lighten`. Distance: `far_grass`. Ground under the grass: `under_grass`, `under_relief`. Meshes: `meshes: Array[GrassMesh]`. `kinds()`, `build_key()`, `average_color()`, `ground_under() -> Vector4`, `apply_to(material)`. Ready ones in `looks/`: meadow, autumn, lush, steppe |
| `GrassMesh` | `mesh` (null = the kit's blade), `weight`, `size`, `map_name`, `mask_texture`; Material: `albedo_texture`, `normal_texture`, `orm_texture`, `alpha_scissor`, `tint`, `palette`, `bend_from_color`. `grows_by_map()`, `build_key()` |
| `GrassWind` | `direction`, `strength`, `speed`, `scale`, `noise`, `blend_time`, `time_override`; `current_direction`, `current_strength`, `offset`, `time`. `tick(delta)` (once a frame), `write()`, static `write_calm()` |
| `GrassQuality` | `density`, `radius`, `near_radius`, `far_density`, `cell_size`, `tiers`, `segments`, `min_blade_pixels`, `near_fade`, `cast_shadows`; inspector buttons Low / Medium / High and the read-only `cost`. static `preset(Level.LOW / MEDIUM / HIGH)`; `apply_preset(level)`, `density_at(distance)`, `blades_per_cell()`, `tier_starts()`, `tier_at(distance)`, `blades_in_tier(tier)`, `segments_in_tier(tier)`, `morph_ends()`, `ring_margin()`, `blades_in_ring()`, `describe()` |
| `GrassClearing` | `group`, `radius`, `soft` |
| `GrassClear3D` | `radius`, `soft` (gizmo and handles in the editor); signal `changed` |
| `GrassStats` | `cells`, `blades`, `cells_in_view`, `blades_in_view`, `draws`, `blades_by_kind`; prints as one line |
| `GrassGlobals` | The shader globals (`ALL`); static `declare()`, `add_to_project()`, `bake_view(look, ground) -> Dictionary`, `write_bake_view(look, ground)` |
| `GrassCells` | static `around(center, radius, size) -> Dictionary[Vector2i, float]`, `rect_of(cell, size)` |
| `GrassBlades` | static `points(count, size, start)`, `kinds_of(count, weights)`, `instance_buffer(points, count, kinds, kind, segments)`, `blade_mesh(segments)`, `tier_meshes(quality, kinds)` |
| `field/grass.gdshader`, `field/grass_cut.gdshader` | The blades, opaque and with alpha scissor (the body is `grass_body.gdshaderinc`) |
| `field/grass_wind.gdshaderinc` | For any shader: `grasskit_wind_wave(xz)`, `grasskit_wind_gust(xz)`, `grasskit_wind_push(xz)` |
| `field/grass_ground.gdshaderinc` | For the game's ground: `grasskit_ground_color(rgb, xz, grass_here)`, `grasskit_painted_grass(xz)`, `grasskit_ground_bands(xz, amount)` |
| `field/grass_color.gdshaderinc` | `grasskit_to_linear(rgb)`, `grasskit_from_linear(rgb)`: the renderer's colours to linear and back (Compatibility converts, the others do not) |
| Editor (plugin) | The 3D view's GrassKit menu and brushes (`editor/grass_paint_tool.gd`), handles (`editor/grass_gizmos.gd`), Project ▸ Tools ▸ GrassKit: Bake the open scene |
