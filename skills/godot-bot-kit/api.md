# BotKit API per piece

Everything under `addons/bot_kit/`. Distances are metres (`_m`), times seconds (`_s`), angles degrees (`_deg`), except `yaw` and `pitch`, in radians.

| Class | What |
|---|---|
| `Bot3D` (@tool, Node3D) | `enabled`, `body` (empty: its parent), `head`, `difficulty`, `weapons: Array[BotWeapon]`, `target_group` (`&"bot_target"`), `turn_body`. Controls: `move_left`, `move_right`, `move_forward`, `move_back`, `jump_action`, `fire_action`, `yaw_value`, `pitch_value`. Eyes: `eye_height_m`, `aim_height_m`, `sight_mask`, `pitch_limit_deg`. Fight: `fight_want`, `strafe_s`, `jump_chance`. Roam: `roam_want`, `navigation_layers`, `arrive_m`, `reach_slack_m`, `stuck_s`, `stuck_m`, `repath_s`. Thinking: `think_s`, `random_seed`. `show_in_game`. Reads: `input: BotInput`, `target`, `seen_s`, `last_seen`, `weapon`, `mode`, `goal`. The game's functions: `is_enemy(node) -> bool`, `choose_target() -> Node3D`, `weapon_score(weapon, distance_m, score) -> float`. Signals `target_changed`, `weapon_changed`, `mode_changed`, `stuck`. `current_difficulty()`, `eye_position()`, `feet()`, `can_see(point, of = null)`, `move(direction)`, `walk_to(point, delta) -> bool`, `look_toward(direction, delta)`, `turn_to(yaw, pitch, delta)`, `aim_and_fire(delta)`, `press(action, strength = 1)`, `release(action)`, `tap(action)`, `jump()`, `stop()`, `random_reachable_point()`, `flat_distance_to(point)`, `path_points()`; constants `FIGHT`, `ROAM`, `THINK_PRIORITY` (-150) |
| `BotInput` | Like `Input`: `is_action_pressed`, `get_action_strength`, `get_action_raw_strength`, `get_axis`, `get_vector`, `is_action_just_pressed`, `is_action_just_released`, `get_value(name, default)`. `press(action, strength)`, `release(action)`, `release_all()`, `set_value(name, value)`, `held()`. Signals `pressed(action, strength)`, `released(action)`, `value_changed(name, value)`, once per change |
| `BotWeapon` (@tool, Resource) | `name`, `fire_action`. When: `score`, `min_m`, `max_m`, `chance`, `keep_m` (-1: the difficulty's), `fire_within_m`. Aim: `projectile_speed_m_s`, `gravity_m_s2`, `lead_max_s`, `aim_height_m` (-1: the bot's). Trigger: `trigger` (`HOLD`, `TAP`, `CHARGE`), `tap_every_s`, `charge_s`, `tap_chance`. `score_at(distance_m)`, `lobs()` |
| `BotDifficulty` (@tool, Resource) | `display_name`. Seeing: `sight_m`, `reaction_s`. Aim: `turn_deg_s`, `aim_error_deg`, `fire_cone_deg`. Firing: `burst_s`, `burst_pause_s`. Moving: `move_scale`, `keep_m`, `chase_chance`, `goal_reach_scale`. `trigger_share()`. Presets: `presets/easy.tres`, `normal.tres`, `hard.tres` |
| `BotGoal3D` (@tool, Node3D) | `enabled`, `priority`, `reach_m`; `wanted(bot) -> bool`. `is_for(bot, from)`; constant `GROUP` |
| `BotMode` (@tool, Node) | `enabled`. To override: `_want(bot) -> float`, `_enter(bot)`, `_tick(bot, delta)`, `_exit(bot)` |
| `BotAim` | static `yaw_of(direction)`, `pitch_of(direction)`, `facing(yaw, pitch)`, `degrees_off(yaw, pitch, want_yaw, want_pitch)`, `lead(from, point, velocity, speed_m_s, most_s)`, `lob_pitch(speed_m_s, gravity_m_s2, flat_m, rise_m)`, `turn_yaw(from, to, step)`; constant `OUT_OF_REACH_PITCH` |
| `BotPath` | static `map_ready(map)`, `find(map, from, to, layers)`, `reaches(map, from, to, layers, slack_m)`; `next(map, from, to, layers, arrive_m, repath_s, delta)`, `clear()`; `goal`, `points`, `index` |
| `BotDebug` (Node3D) | What `show_in_game` draws: an internal child of the bot. `show_bot(bot, firing)` |
| Editor (plugin) | The bot's gizmo (sight, cone, fight distance, `eye_height_m` and `aim_height_m` handles) and the goal's (reach, `reach_m` handle): `editor/bot_gizmo_3d.gd`, `editor/bot_handles.gd`. The warnings are the nodes' |
